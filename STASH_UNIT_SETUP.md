# Настройка персонажа "Сундук/Инвентарь"

## Инструкция по добавлению в Excel файл

Для добавления персонажа "сундук/инвентарь" в базу данных необходимо:

1. **Открыть Excel файл**: `All cards wave 1-9 21_02_2024 with categories for builder (2).xlsx`
2. **Перейти на лист "Units"**
3. **Добавить новую строку** с данными персонажа "Stash" или "Inventory":

### Обязательные поля:
- **Столбец A (Name)**: `Stash` или `Inventory` (на английском, как и все остальные названия в Excel)
- **Столбцы B-V (Factions)**: Поставить `X` во ВСЕХ столбцах фракций, чтобы персонаж был доступен всем фракциям
- **Столбцы W-AB (Prereq - Weapon types)**: Поставить `X` во ВСЕХ столбцах типов оружия
- **Столбцы AC-AN (Access)**: Поставить `X` во ВСЕХ столбцах доступа к категориям предметов:
  - Upgrades
  - Wasteland Items
  - Advanced Items
  - High Tech Items
  - Usable Items
  - Robots Items
  - Automatron Items
  - Creature Items
  - Dog Items
  - Super Mutant Items
  - Standart Item
  - Faction Items
- **Столбец AT/AU/AS/AQ (Cost)**: Установить стоимость `0` (стоимость предметов сундука не учитывается в общей сумме очков)

### Важно:
- Персонаж должен иметь доступ ко ВСЕМ типам предметов
- Стоимость предметов, добавленных этому персонажу, автоматически исключается из расчета общей стоимости армии
- После добавления в Excel, запустить скрипт `tools/update_db.py` для обновления базы данных

## Использование в приложении

После добавления персонажа в базу данных:
1. В режиме Campaign Mode перейти на вкладку "Units"
2. Нажать "Add model"
3. Выбрать персонажа "Stash" или "Inventory" (название будет отображаться так, как указано в Excel)
4. Персонаж будет доступен всем фракциям и будет иметь доступ ко всем предметам
5. Стоимость предметов этого персонажа не будет учитываться в общей сумме очков армии
